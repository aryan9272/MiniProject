# 📚 Online Coding Classroom

An **Online Coding Classroom** built using **Python and Django**.  
This project provides a virtual platform where users can learn, practice coding, and interact in an organized classroom environment.

---

## 🚀 Features
- Interactive coding classroom
- User-friendly interface
- Built with Django framework
- Uses virtual environment (venv)
- Easy one-click setup using `run.bat`

---

## 🛠️ Tech Stack
- Python
- Django
- HTML, CSS
- SQLite (default database)

---

## ▶️ How to Run Locally

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Run Using `run.bat`
Just double-click the `run.bat` file  
**OR** run in terminal:
```bash
run.bat
```

---

## ⚙️ What `run.bat` Does
- Activates the virtual environment (`venv`)
- Installs required dependencies (if needed)
- Applies migrations
- Starts the Django development server

---

## 🌐 Access the Project
After running, open your browser and go to:
```
http://127.0.0.1:8000/
```

---

## 📌 Note
- Make sure Python is installed on your system
- `venv` folder is already included, so no need to create a new virtual environment
